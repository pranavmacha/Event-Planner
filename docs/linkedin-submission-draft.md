I built **Gatherly** for Google Prompt Wars Virtual Challenge 5: “Celebration and Event Planner.”

Planning a family celebration gets difficult when the guest list grows, the budget shrinks, and the date moves. Gatherly keeps those decisions connected.

Describe a celebration, turn it into an editable budget and timeline, compare vendor quotations, and ask to change the plan. Before applying a revision, you can see the financial impact, earlier deadlines and unresolved constraints. Discard it, apply it, or restore the previous version.

Gemini helps interpret preferences and changes and explain vendor tradeoffs. Application code owns the arithmetic, validation, dependencies, ownership and saved revisions. An explicitly labeled demo mode works without an API key.

Built with React, TypeScript, Tailwind, FastAPI, SQLAlchemy and the official Google Gen AI Python SDK.
